# RecoverX

## AI-Powered Payment Recovery Intelligence

RecoverX is an AI-powered payment recovery prototype designed to analyze failed payment transactions, estimate recovery probability, and recommend intelligent recovery actions.

## Core Features

- Payment transaction analytics
- Failed payment analysis
- Machine learning recovery prediction
- Recovery probability estimation
- Expected recovery calculation
- Policy-based decision engine
- AI recovery agent
- Explainable recovery recommendations
- Interactive Streamlit dashboard
